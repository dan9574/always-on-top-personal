# Attribution and independence

Pinned Notes Personal is an independently maintained plugin (`personal-pinned-notes`).
It is not published or maintained by n23eos, and does not use the original plugin's update identity.

This repository started from n23eos/obsidian-always-on-top-tasks, tag 0.7.0 (MIT).
Its original implementation is archived locally under the ignored `old/` directory and retained in Git history.
The desktop bridge design was informed by that project; its source credits the MIT-licensed
obsidian-synaptic-hatch project for Electron remote resolution. The original MIT copyright
notice and license remain in LICENSE. No affiliation or endorsement is implied.

The current native editor, shortcut lifecycle and display filtering implementation are maintained
as this personal project. Obsidian and Electron provide the host editor and window APIs.
